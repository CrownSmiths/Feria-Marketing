## Tailwindcss CLI
El proyecto usa tailwindcss sin la encesidad de usar npm. Este va compilando los css de input.css a output.css, este ultimo contiene todo el css. Para realizar compilacion automatica es necesario inicializar el proceso:

- `./tailwindcss -i ./css/input.css -o ./css/output.css --watch`
